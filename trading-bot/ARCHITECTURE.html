TradingView → Webull Options Auto-Trader

A FastAPI webhook service that receives TradingView alerts, buys the nearest-weekly ATM option on the signalled side, and autonomously manages scale-outs, breakeven, trailing stops, and stop-loss on a one-minute cadence.

Python FastAPI Webull OpenAPI asyncio Options / 0-DTE

01 System Flow

A TradingView strategy fires a JSON alert on a 5-minute bar. Cloudflare Tunnel forwards it to the local FastAPI server. The server authenticates, de-duplicates, applies risk gates, enters the position, and hands off to a background exit engine that watches premium until flat.

Two feedback loops keep state honest: the Exit Engine polls quotes every 60s to drive scale-outs, and the Order-Events gRPC stream corrects each position's cost basis to the broker's real average fill price.

02 Application Components

API / ORCHESTRATION app/main.py

FastAPI Entry Point

Hosts the HTTP surface and wires every component together at startup via a lifespan context.

  • POST /webhook — validates secret, dedupes, routes to strategy
  • GET /health — dry-run flag, account, open count, daily P&L
  • GET /positions — live tracked positions
  • Constant-time secret check via hmac.compare_digest
  • TTL in-memory dedupe on ticker|signal|action|bar_time
  • Startup reconciliation against broker-held positions
STRATEGY app/strategy.py

Entry Logic & Gates

Decides whether a signal becomes a trade, then sizes and submits the opening order.

  • Gates: universe membership, RTH window, daily-loss halt, one-per-symbol, max concurrent
  • Selects contract & checks the bid/ask spread gate
  • Prices entry off market / bid / ask / mid + slippage buffer
  • Places BUY_OPEN and records a Position
EXIT ENGINE app/position_manager.py

Exit Management Loop

Background asyncio task that evaluates every open position on a 1-minute cadence.

  • Stop-loss → breakeven arm → TP1 → TP2 → trailing
  • Tracks peak premium to drive the trailing stop
  • Records realized P&L per partial fill (×100 multiplier)
  • Never dies: each cycle wrapped in exception guard
  • Hot-reloads config.yaml each cycle
BROKER ADAPTER app/webull_client.py

Webull OpenAPI Client

Isolates all broker calls; a full dry-run simulator lets the pipeline be wire-tested offline.

  • Auth, account resolution, contract selection, quotes, orders, positions
  • Expiry rules: nearest_weekly / zero_dte / nearest_monthly
  • Builds OCC symbols & option-leg order payloads in one place
  • Dry-run: simulated strikes, quotes & fills via set_sim_price
EVENTS app/order_events.py

Order-Fill Subscriber

Daemon-thread gRPC subscriber that keeps cost basis accurate for the exit engine.

  • Listens for ORDER_STATUS_CHANGED
  • On an entry fill, rewrites Position.basis to true avg price
  • Defensive field reads across region variants
  • No-op in dry-run (fills are synchronous)
STATE app/state.py

Crash-Recovery Store

Thread-safe in-memory store persisted atomically to a gitignored state.json.

  • Tracked positions keyed by underlying symbol
  • Running daily realized P&L with automatic day-roll
  • Atomic writes via temp-file replace
  • Broker stays the source of truth; used only to resume mid-trade
CONFIG app/config.py

Secrets & Params

Splits sensitive secrets from tunable trading parameters.

  • Secrets loaded once from .env (frozen dataclass)
  • Params re-read from config.yaml on demand (hot reload)
  • Endpoint hosts choose sandbox vs. production
MODELS app/models.py

Typed Data Structures

Dataclasses shared across the app.

  • Signal — parsed inbound alert + dedupe key
  • OptionContract — resolved tradable option
  • Quote — bid/ask with mid & spread_pct
  • Position — live position with TP/BE/peak state

03 Exit Ladder

Every rung is configurable in config.yaml. Percentages are measured against the option premium relative to entry basis, not the underlying.

−20%
Stop-LossClose all contracts if premium falls 20% below entry basis.
+20%
Breakeven ArmStop moves up to the entry basis — the trade can no longer become a loser.
+30%
TP1 — sell 4First target hit; sell 4 of 10 contracts and arm a 10% trailing stop on the remainder.
+50%
TP2 — sell 4Second target; sell 4 more, leaving 2 runners under the trailing stop.
−10%
Trailing StopAfter TP1, everything left trails 10% off the peak premium seen.

06 Alert Payload Contract

TradingView must POST JSON matching this shape. secret, ticker, action, and price are required; action must be CALL or PUT.
